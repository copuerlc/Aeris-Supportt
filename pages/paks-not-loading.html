Troubleshooting Guide

Paks Not Loading

If you launch Aeris but don't see the custom loading screen, your PAK files most likely weren't loaded correctly.

1

Check your loading screen

Launch the build and check whether the custom Aeris loading screen appears.

If you don't see the custom loading screen, this means your PAK files were not loaded.

2

Download the required file

Download the required file provided by Aeris Support. This file needs to be placed inside the correct Fortnite directory.

Download File
3

Open the NVAftermath folder

Navigate to the following location inside your 14.40 installation:

14.40\Engine\Binaries\ThirdParty\NVIDIA\NVaftermath\Win64
4

Place the file inside Win64

Take the file you downloaded and place it directly inside the Win64 folder.

14.40\Engine\Binaries\ThirdParty\NVIDIA\NVaftermath\Win64

Still not working?

If the custom loading screen still doesn't appear after placing the file in the correct directory, open an Aeris Support ticket and provide as much information as possible about your installation.

✓ Fix completed Restart the 14.40 build and check whether the custom loading screen appears.
