TROUBLESHOOTING

Paks Not Loading

If you don't see the custom loading screen, your PAK files didn't get loaded correctly.

STEP 01

Check the custom loading screen

Launch your 14.40 build and check whether the custom loading screen appears.

If you don't see the custom loading screen, this means your PAK files didn't get loaded.

STEP 02

Download the required file

Download the file below. This file needs to be placed inside your 14.40 installation.

Download Required File
STEP 03

Open the required folder

Navigate to the following location: 

14.40\Engine\Binaries\ThirdParty\NVIDIA\NVaftermath\Win64
STEP 04

Place the file inside Win64

Take the downloaded file and place it directly inside the Win64 folder. 

14.40\Engine\Binaries\ThirdParty\NVIDIA\NVaftermath\Win64
FINISHED

Launch Aeris again

After placing the file in the correct folder, launch your 14.40 build again and check for the custom loading screen.

STILL NOT WORKING?

Contact Aeris Support

If your custom loading screen still doesn't appear, open a support ticket and provide details about your installation.
